# 🧮 Two Sum — LeetCode 1

## 🧠 Problem Summary
Given an array of integers `nums` and a target integer, return the indices of the two numbers that sum to the target.

## 🚀 Solution Approach (Optimized — O(n))
We use a HashMap to store values as we iterate:
- Key → number  
- Value → index  
- For each element, compute `target - nums[i]` and check if it exists.

Performance
	•	Runtime: 2 ms (Beats 99.12%)
	•	Memory: 47 MB (Beats ~14%)
